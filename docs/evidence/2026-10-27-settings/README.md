# 설정·문의·앱 정보 복원 검증 (2026-10-27)

## 구현

- 홈 목표 영역 옆 설정 버튼 → 별도 설정 시트. 상단 툴바에 세 번째 아이콘을 넣으면 SE 제목이 잘려 목표 영역으로 옮겼다.
- 목표 설정/변경과 검색 언어의 현재 위치 안내. 별도 저장 로직이나 계산기는 추가하지 않았다.
- 기존 문의 주소로 MessageUI 작성 화면을 제공한다. 사용자가 전송하며 기록·진단·식별자를 자동 첨부하지 않는다. 메일 미설정 시 주소 복사 안내, 항상 사용 가능한 주소 복사 버튼과 완료 표시.
- Bundle의 버전·빌드 표시, USDA SR Legacy/식약처 데이터 출처, 번들 라이선스 전문 열람.
- ThirdPartyNotices.txt는 Package.resolved의 11개 패키지와 동일 revision의 로컬 checkout LICENSE/NOTICE 원문을 모았다. 패키지 업데이트 시 함께 갱신한다.

## 범위와 한계

- 메일 계정이 설정된 실기기의 작성기 표시·취소·전송 및 전송 오류 UI는 미검증이다. 이메일을 전송하지 않았다.
- 최종 변경 후 Release/실기기 설치·기본 활성화·배포는 하지 않았다. 이전 출시 준비 Release 빌드는 이 기능 추가 전 결과다.
- 앱 정보는 로컬 Bundle/번들 텍스트만 읽으며 설정 화면에 RecordHomeViewModel이나 저장소 의존성이 없다.
- 실제 사용자 백업 검증, 지원 OS/계산기 정책, 배포 계정/API 주입 확인은 출시 준비 계획의 미완료 조건으로 유지한다.
