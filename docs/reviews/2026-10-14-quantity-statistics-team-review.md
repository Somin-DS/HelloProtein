## 의견 조정과 결정

### 계산 기준을 저장하는 schema 3

검색 중 rawProtein과 기준량이 있지만 기존 영속 기록은 최종 단백질·quantity만 갖는다. 기존 단백질 직접 수정은 quantity와 source를 유지하므로 `source.search`만으로 원래 공급자 근거를 복원할 수 없다. 저장 후 수량 편집에서 반올림 누적을 막기 위해 신규 계산 기록에 불변 basis를 저장하고 schema 3로 명시 승격한다.

기존 기록은 basis nil로 보존하며 기존 이름·단백질 편집만 유지한다. 자동 전환이나 재조회로 복원하지 않는다. 신규 기록의 직접 단백질 수정은 사용자 명시 전환 후 userDefined 기준으로 저장하며, 공급자 식별자를 제거한다. 즐겨찾기는 기존 이름·단백질만 저장한다는 안내를 유지한다.

### 같은 단위로만 비례 계산

이번 범위는 g→g, mL→mL 등 원래 단위의 양 변경이다. 질량·부피 환산이나 밀도·인분 추정은 추가하지 않는다. 최종 결과만 반올림하며 1.005g/100g × 200g = 2.01g을 필수 사례로 삼는다. 편집 화면 기준값에는 원시 소수 정밀도를 표시한다.

### 통계의 음수와 분모

기획 초기안은 음수 날짜를 평균에서 제외하고 제외 일수를 표시하는 방식이었다. 개발안은 기존 일일 정본과 signed 합계를 일치시키는 방식이었다. 최종안은 **signed 값 그대로 합계·기록일 평균에 포함하고 과거 음수 보정 경고와 해당 날짜를 보여준다.** 숫자를 수정하거나 실제 섭취량이라고 단정하지 않는다. 기획·그로스가 실제 초안 재검토에서 이 선택을 수용했다.

기록 없음과 명시적인 legacy 0g은 분리한다. 기록일 평균의 분모는 상세 기록 또는 legacy adjustment가 있는 날짜 수다. 빈 DailyLog는 관측일이 아니다. 목표는 해당 날짜 목표만 사용한다. 기간 달성률과 연속 달성은 이번 범위에서 제외하고 날짜별 목표 비교만 제공한다.

### 화면 범위를 좁혀 기존 기록 흐름에 연결

검색 다중 선택과 기존 추가 버튼을 유지한다. 선택 행의 수량 변경은 추가 시트 내부 편집 화면으로 연결한다. 통계는 홈 상단 차트 버튼에서 단일 push 화면으로 연다. 과거 문서의 미확정 하단 3버튼이나 전체 탭바를 도입하지 않는다.

7일/30일은 선택 끝 날짜를 기준으로 한 기간이며 ‘이번 주’ 대신 실제 날짜와 ‘최근 기간’이라는 표현을 쓴다. 통계 날짜를 탭하면 홈의 그 날짜로 돌아가 수정할 수 있다. 조회는 파일 쓰기 없이 기존 VM의 확정 snapshot만 사용한다.
