# UI 시안 (docs/ui-preview)

`index.html`을 브라우저에서 열면 됩니다. 서버·빌드·네트워크 없이 동작하며 제품 코드·저장소와 연결되지 않습니다.

```sh
open docs/ui-preview/index.html
```

## 구성

1. **세 화면 나란히**: 기존 앱 실행 캡처, 현재 SwiftUI 프로토타입 실행 캡처(둘 다 `../evidence/2026-09-28-simulator/`), 권장안(클릭 가능). Figma 와이어프레임은 이번 세션에서 접근이 거부되어 이미지가 없고, 구성 요약만 `docs/figma-designer-wireframe-review.md`에서 옮겼습니다.
2. **필수 상태 갤러리**: 홈 4상태, 과거 기록 4상태, 추가/편집 5상태, 미확정 4상태, 목표 4상태, 검색/즐겨찾기 3상태, 히스토리 2상태, 설정, 복구 3상태, 온보딩·로딩. 정지 화면이며 클릭되지 않습니다.
3. **합성 fixture**: 긴 영어 이름, 소수량, 빈 날짜, 이전 버전 합계만 있던 날짜, 음수 보정값. 실제 사용자 데이터가 아닙니다.

## 상단 전환

| 전환 | 값 | URL 해시 |
| --- | --- | --- |
| 언어 | 한국어 / English | `#lang=ko` / `#lang=en` |
| 글자 크기 | 기본 / 큰 글자(약 1.3배, iOS AX 근사) | `#scale=1` / `#scale=1.3` |
| 구조 | A 홈+액션 바(권장) / B 3탭+FAB | `#struct=A` / `#struct=B` |
| 테마 | 라이트 / 다크(새 제안, 지원 미결정) | `#theme=light` / `#theme=dark` |

해시는 `&`로 이어 쓸 수 있습니다. 예: `index.html#lang=en&struct=B&theme=dark&scale=1.3`

## 권장안(클릭 가능)에서 따라갈 수 있는 흐름

- 날짜 띠·‹ ›·오늘 → 날짜 이동. 히스토리 아이콘 → 캘린더/그래프 → 날짜 탭 → 그 날짜로 홈 복귀.
- ＋ → 추가 시트(직접 입력/검색/즐겨찾기 탭). 검색·즐겨찾기는 "후속 구현" 표시가 있는 설계용 화면입니다.
- 저장 버튼은 각본대로 동작합니다: 빈 입력 첫 저장 = 검증 오류(값이 자동으로 채워짐) → 다시 저장 = 성공. 세션 내 두 번째 성공 저장 시도 = 저장 실패 경고(시트 유지), 세 번째 = 저장 결과 미확정(필드 잠금, 홈 배너, ＋·행 비활성). 미확정 상태에서 "저장 결과 확인"을 누르면 1회차 재확인 실패 → 2회차 미반영(입력 재개) → 3회차 반영·닫힘 순서입니다.
- 기록 행 → 편집 시트(삭제 포함). 이전 버전 합계 박스 → "하루 총량 수정" 시트.
- 설정 → 하루 목표 → 계산기 시트. 입력이 있는 시트에서 취소 → 버리기 확인.
- 미확정 상태에서 취소를 누르면 "입력한 내용은 남지 않아요" 확인 뒤 닫히고 홈 배너가 이어받습니다(제품 현재 동작과 같음).
- 히스토리 그래프는 선택 날짜가 속한 주를 보여주고, 목표선은 날짜별 목표 이력을 따릅니다. 9/23이 속한 주는 목표 이력이 없어 목표선이 없고, 오늘(9/28)이 속한 주에는 있습니다.
- "처음 상태로" 링크는 fixture 원본 복사본과 저장·재확인 각본 카운터를 함께 초기화합니다.

## 표기 규칙

- `new` 태그·"새 제안": 기존 앱·Figma 어디에도 없는 시각 결정.
- "후속 구현 — 시안에만 있음": 현재 코드에 없는 화면.
- "권장안 · 미확정": 사용자 결정 전. 제품 화면 교체를 시작하지 않습니다.

## 검증한 범위

- macOS의 Chrome headless로 라이트/다크, 한국어/영어, 구조 A/B, 큰 글자, 1200px·400px 폭 렌더를 확인했습니다(JS 오류 없음, 클릭용 1개 + 갤러리 36개 폰 프레임 렌더. 초기화·목표선·미확정 취소 정책은 headless에서 스크립트로 확인).
- 실기기·VoiceOver·실제 Dynamic Type·색 대비 측정기는 사용하지 않았습니다. 대비 수치는 `docs/ui-spec.md`에 계산값으로만 적혀 있습니다.
- 서체: 제품의 Binggrae-Bold를 웹에서 로드할 수 없어 숫자에 Fredoka(구글 폰트, 오프라인이면 시스템 sans)를 대체 표시합니다. 본문은 Noto Sans KR/시스템.
