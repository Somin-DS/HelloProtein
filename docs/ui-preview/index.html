Hello Protein UI 시안 권장안 · 미확정

기존 앱 · Figma 의도 · 현재 프로토타입을 같은 합성 데이터로 비교하고, 권장 화면 구조와 주요 상태를 클릭해 볼 수 있는 검토용 시안입니다. 제품 저장소에 연결되지 않으며, 저장·검색·목표 편집은 화면 전환만 흉내 냅니다. 근거는 docs/ui-audit.md, 명세는 docs/ui-spec.md.

서체 안내: 제품의 Binggrae-Bold는 웹에서 불러올 수 없어 숫자에 Fredoka를 대체 표시합니다. 본문은 시스템/Noto Sans KR. 실제 앱에서는 숫자만 Binggrae-Bold, 본문은 시스템 서체가 제안입니다.

유지한 기존 요소크림 배경 #FFFEF9, 민트 #C8F4C2, 브랜드 그린 #ACDDAD, 베이지 칩 #F2F1E2, 계란 워드마크, 숫자용 둥근 굵은 서체, 설정 항목 4개, 계산기 공식.

구현하지 않은 것(시안에만 있음)검색·즐겨찾기 탭, 히스토리 캘린더/그래프, 설정·목표 화면, 온보딩. 시안에서 후속 구현 표시. 저장 동작은 흉내이며 데이터 계약(편집 날짜 고정, 미확정 시 입력 잠금 등)은 명세 §6 그대로입니다.
